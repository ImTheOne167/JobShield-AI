# JobShield AI

JobShield AI is a web-based application designed to help users analyze job postings and identify potentially suspicious or fake job opportunities.

## Features

- Job posting analysis
- Risk score calculation
- Genuine, Suspicious, and Fake classification
- Recruiter verification
- My Analyses history
- Knowledge Base
- Simple and user-friendly dashboard

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap

## How to Run

1. Install Python.
2. Install Flask:
   `pip install flask`
3. Run the application:
   `python app.py`
4. Open the local URL shown in the terminal.
